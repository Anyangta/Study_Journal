## 방법 B — 엑셀로 만들기

파이썬을 안 쓰신다면 이렇게 하세요. 다만 **위아래 두 패널이 x축을 공유하는 형태는
엑셀에서 차트 2개를 만들어 겹쳐 놓는 방식**이라 손이 좀 갑니다.

### 1. 데이터 넣기

`fig2_data.csv`를 엑셀로 엽니다. A열 `time_s`, B열 `latency_s`, C열 `throughput_krec_s`.

### 2. 위 패널 (지연)

1. A열 + B열 선택 → **삽입 → 분산형 → 곡선/직선이 있는 분산형**
2. 세로축 제목 `latency (s)`, **가로축 제목은 비움** (아래 차트에만 씀)
3. 가로축 범위를 **−25 ~ 55**로 고정 (축 서식 → 최소/최대)

### 3. 아래 패널 (처리량)

1. A열 + C열로 같은 방식의 분산형 차트를 하나 더
2. 세로축 제목 `throughput (k rec/s)`, 가로축 제목 `time relative to failure (s)`
3. **가로축 범위를 위 차트와 똑같이 −25 ~ 55**로 고정

### 4. 기준선 넣기

엑셀에는 "가로선 하나 긋기"가 없어서 **보조 계열**로 만듭니다.

**가로 점선 (steady, λ)**
- 빈 열에 그 값을 전 행에 채웁니다 (예: D열 전체에 `0.2276`)
- 차트에 그 계열을 추가 → 선 스타일을 **파선, 회색**으로

**세로선 (kill, restored)**
- 두 칸짜리 보조 데이터를 만듭니다:

  | x | y |
  |---|---|
  | 0 | 0 |
  | 0 | 95 |   ← 위 패널 최대값 정도

- 이 두 점을 분산형 계열로 추가 → 선 **빨강 실선**
- `restored`는 x를 `1.077`로 해서 같은 방식, **초록 파선**

### 5. 두 차트 붙이기

1. 두 차트의 **플롯 영역 너비를 똑같이** 맞춥니다 (차트 영역 서식 → 크기)
2. 위 차트 높이 : 아래 차트 높이 = **2 : 1**
3. 위 차트의 **가로축 눈금 레이블을 숨김** (축 서식 → 레이블 위치: 없음)
4. 두 차트를 세로로 붙여 놓고 **함께 그룹화**

### 6. 논문용 마무리

- [ ] 글씨 크기 **8pt** (본문 10pt보다 작지 않게)
- [ ] 격자는 **가로만, 옅은 회색**
- [ ] 범례 없음 (선이 2개뿐이고 축 제목으로 구분됨)
- [ ] 차트 테두리 없음
- [ ] 그림 폭을 **3.4인치**(2단 1칼럼)로
- [ ] 워드에는 **PDF로** 넣기 — 엑셀 차트는 복사→선택하여 붙여넣기→**그림(PDF)**

## 이 그림이 보여주는 것 (캡션 쓸 때)

**위 패널** — 장애 후 지연이 89초까지 치솟았다가 **삼각형으로 감소**해 정상
수준(0.23초)으로 돌아옵니다. 이게 논문 III.B의 삼각형 근사입니다.

**아래 패널 — 여기가 메커니즘입니다.** 장애 중 처리량이 0으로 떨어졌다가, 복구 후
**λ(32.7k)의 약 3배인 100k 이상으로** 올라가 밀린 것을 빼고, 다 빼고 나면 다시
λ로 돌아옵니다.

> **즉 backlog가 `μ_d − λ`로 줄어든다는 모델의 핵심이 그림에 그대로 보입니다.**
> 캡션에서 이 점을 짚으면 그림이 훨씬 강해집니다.

## 주의 — 아무 run이나 쓰면 안 됩니다

이 그림은 원래 **복구에 실패한 run**(`m10_..._c32_m55_0`, steady 102초)에서
그려져 있었습니다. 지연이 안 내려가고 정체하다 재상승하는 궤적이라 캡션과
정반대였습니다.

다른 에피소드로 바꾸고 싶으면 `../검증실험/fig3_episodes.csv`에서 **반드시**
이 조건을 만족하는 것을 고르세요:

```
run_saturated = 0  AND  run_unstable = 0  AND  run_overloaded = 0
D_eff_s  <= 12          (복구가 실제로 끝난 것)
peak_lat_s >= 6         (스파이크가 보여야 함)
lambda * peak / (mu_drain - lambda) <= 45     (배수가 창 안에서 완료)
```

서버의 `plot.py`에 `pick_trace_run()`으로 이 조건이 들어가 있습니다.
