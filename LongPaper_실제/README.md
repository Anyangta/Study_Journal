# LongPaper_실제 — 저자가 직접 쓰는 최종본

*2026-09-13 시작. 마감 2026-09-15.*

---

## 왜 이 폴더를 따로 만드는가

`LONG_Paper/paper_EN.md`는 **AI가 쓴 문장**입니다. 데이터·모델·실험은 전부
진짜지만, 영어 문장 자체는 저자의 것이 아닙니다. 그 상태로 투고하면 문제가 되는
것은 연구가 아니라 **문장의 저자성**입니다.

이 폴더는 그걸 해결합니다. **영어 문장은 저자가 직접 씁니다.**

---

## 작업 방식

절마다 파일 하나. 각 파일은 이렇게 생겼습니다.

| 칸 | 누가 | 내용 |
|---|---|---|
| **① 이 절이 해야 할 일** | Claude | 이 절이 독자의 어떤 질문에 답해야 하는지 |
| **② 반드시 들어갈 것** | Claude | 수치와 그 출처. 빠지면 주장이 무근거가 되는 것 |
| **③ 지켜야 할 한정** | Claude | 약화하면 과장이 되는 표현들 |
| **④ 쓰면 안 되는 것** | Claude | 리젝 사유가 되는 표현 |
| **⑤ 초안** | **저자** | **여기에 직접 영어로 씁니다** |
| **⑥ 검증** | Claude | 수치가 맞는지, 주장이 데이터를 넘는지, 문법 |

**Claude는 ⑤를 대신 쓰지 않습니다.** ①~④로 뼈대를 주고, ⑥에서 틀린 것을
잡습니다. 문법·오타 교정과 사실 검증은 대부분의 학회가 허용 범위로 봅니다.
