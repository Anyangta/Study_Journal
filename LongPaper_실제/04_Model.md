## ② 반드시 들어갈 것

### 기호 (처음 나올 때 전부 정의)

| 기호 | 뜻 |
|---|---|
| λ | 입력률 |
| μ | 명목 최대 처리율 |
| ρ = λ/μ | 가동률 |
| τ | 체크포인트 주기 |
| a | 장애 시 마지막 완료 체크포인트의 나이 |
| **D** | **실효 공백 (effective outage)** — 순수 엔진 중단시간이 아님 |
| μ_d | 복구 중 처리율 |
| ρ_d = λ/μ_d | |
| M | 평균 장애 간격 |
| δ | 지연 등가 체크포인트 비용 |
| ℓ₀ | 지연의 바닥 |

### 수식 — 그대로 가져오시면 됩니다

```
B₀ = λ(a + D)                                                    (1)
T_c = λ(a + D) / (μ_d − λ)                                       (2)
A = μ_d · ½(a + D) · T_c = μ_d·λ·(a + D)² / (2(μ_d − λ))         (3)
E[(a + D)²] = τ²/3 + τD + D²                                     (4)
L̄(τ) = ℓ₀ + δ²/(2(1−ρ)τ) + [μ_d/(2(μ_d−λ)M)]·(τ²/3 + τD + D²)    (5)
δ²·M·(1−ρ_d)/(1−ρ) = τ²·(2τ/3 + D)                               (6)
τ* ≈ (1.5·δ²M)^(1/3)                          [D ≪ τ]            (7)
τ*_cap ≈ √(2·δ_cap·M/ρ)                                          (8)
λ(τ/2 + D)/(μ_d − λ) + D < M                                     (9)
```

### 말로 반드시 써야 할 것 세 가지

1. **왜 `μ_d − λ`인가** — 복구 중에도 입력이 계속 들어오므로 backlog는 전체
   처리율이 아니라 잔여 용량으로만 줄어든다. **이 논문의 핵심 메커니즘입니다.**
2. **왜 제곱인가** — 나이가 길수록 (ㄱ) 밀린 양이 늘고 (ㄴ) 그걸 빼는 시간도
   같이 는다. 둘 다 `(a+D)`에 비례하므로 곱하면 제곱.
3. **`a ~ U(0, τ)` 인 이유** — 장애가 체크포인트 일정과 독립이므로.
   그래서 `E[a²] = τ²/3` (평균의 제곱 `τ²/4`가 아님)

## ③ 지켜야 할 한정 — 이 절에 특히 많습니다

| 반드시 | 이유 |
|---|---|
| **"under an approximately linear backlog drain"** | 삼각형은 근사입니다. 실측이 정확히 삼각형인 건 아님 |
| **D는 effective outage** | `latest_ack_timestamp` 기준이라 체크포인트 완료 시점과 복원 기준점의 차이를 일부 포함. 순수 엔진 중단시간이 아님 |
| 식 (7)은 **점근값** | 측정 범위 지수는 0.41~0.34. "cube root"라고만 쓰면 과장 |
| 식 (8)은 **참조선일 뿐** | "Jayasekara [4]의 정확한 활용률 최적값을 재현한다고 주장하지 않는다"를 명시 |
| 식 (9)는 **first-moment 근사** | deterministic bound 아님. 개별 장애가 항상 만족한다고 보장 못 함 |

> 이 다섯 개는 **심사자가 가장 먼저 찌르는 자리**입니다. 미리 한정해두면
> 오히려 신뢰가 올라갑니다.

## ④ 쓰면 안 되는 것

| ❌ | 왜 |
|---|---|
| "hard bound" / "stability limit" (식 9) | 평균 부하 근사 |
| "the optimum is the cube root of M" | 점근값. 실제 지수는 0.41~0.34 |
| "our baseline reproduces the utilization optimum" | 아님. 우리 용량 회계로 만든 참조선 |
| 유도 전 과정을 다 쓰기 | 6쪽입니다. **가정 → 결과 식 → 그 식이 말하는 것** |
