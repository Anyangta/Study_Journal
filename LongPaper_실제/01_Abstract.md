## ① 이 절이 해야 할 일

초록은 **다섯 가지**를 순서대로 말합니다. 하나라도 빠지면 안 읽힙니다.

| # | 무엇 | 분량 |
|---|---|---|
| 1 | **문제** — 주기를 정해야 하는데 정답이 없다 | 1문장 |
| 2 | **기존 답과 그 가정** — `√(2δM)`을 쓴다. 그 식은 두 가정 위에 있다 | 1~2문장 |
| 3 | **왜 깨지나** — durable log에서는 일이 안 사라지고, 복구 중에도 입력이 들어온다 → backlog가 `μ_d−λ`로만 빠짐 → 비용이 **제곱** | 2문장 |
| 4 | **우리가 한 것 + 결과 수치** | 2~3문장 |
| 5 | **무엇을 검증했고 무엇을 못 했나** | 1문장 |

> **5번이 중요합니다.** "구조는 검증했고 최적점 위치는 아직"이라고 초록에서
> 먼저 밝히면, 심사자가 R²=0.996을 예측 정확도로 오해할 여지가 사라집니다.

## ② 반드시 들어갈 것

| 수치 | 값 | 출처 |
|---|---|---|
| 기준 조건 회귀 | **R² = 0.996, 기울기 1.107** | 100k key·ρ=0.50, 에피소드 30개 |
| 두 번째 조건 | **R² = 0.982, 기울기 1.092** | 200k key·ρ≈0.30, 에피소드 61개 |

**수치는 2~3개면 충분합니다.** 0.43–0.61, 255 runs, 22 runs 같은 부차 수치는
초록에 넣지 마세요 — 본문에 있습니다.

## ③ 지켜야 할 한정 (약화하면 과장이 됨)

| 반드시 | 이유 |
|---|---|
| **structural validation** 이라고 명시 | peak latency를 같은 에피소드에서 재므로 out-of-sample 예측이 아님 |
| **"approaches" M^(1/3)** | 점근값입니다. 측정 범위 지수는 0.41~0.34 |
| **R²는 회귀의 값** | 적합 파라미터가 없는 것은 **기하식**이고, R²는 기울기·절편을 적합한 선형회귀의 값 |
| **"under a linear backlog-drain approximation"** | 삼각형 근사를 쓴다는 전제를 밝혀야 함 |
| 마지막 문장에 **"remains future work"** | 최적점 독립 검증은 안 했음 |

## ④ 쓰면 안 되는 것

| ❌ | 왜 |
|---|---|
| "predicts the optimal interval accurately" | 최적점 위치는 검증 안 됨 |
| "proves" / "demonstrates conclusively" | 구조 검증이지 증명이 아님 |
| "parameter-free R²" | R²는 회귀값. 기하식이 parameter-free인 것 |
| "first to ..." / "no prior work considered latency" | Zhuang·Zhang·Jayasekara가 했음 |
| 2노드 결과를 network distance 탓으로 | topology와 storage가 같이 바뀜 |
| "hard bound" (안정 조건) | first-moment 근사일 뿐 |
