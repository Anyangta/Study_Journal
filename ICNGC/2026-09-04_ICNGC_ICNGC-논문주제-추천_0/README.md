     - 동일 마이크로서비스 데모(예: online-boutique)를 mesh 유무/종류별로 배포해 지연·처리량·리소스 사용량 비교
  3. **서버리스(FaaS) 콜드스타트 완화**
     - OpenFaaS/Knative에서 호출 패턴별 콜드스타트 빈도·지연 측정 후 프리워밍/배치 전략으로 개선 효과 검증
