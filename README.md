# Study Journal

여러 로컬 환경(PC A, PC B, Claude Code on the web 등)을 오가며 Claude Code로 작업할 때,
세션의 맥락과 진행 상황을 이어가기 위한 **작업 기억 저장소**입니다.

## 왜 필요한가

Claude Code 세션은 로컬 환경이 바뀌면 이전 대화나 작업 맥락을 알 수 없습니다.
이 저장소에 분야별로 작업 기록을 남겨두면, 다른 로컬에서 이 저장소를 pull 받아
Claude Code에게 관련 기록을 읽게 함으로써 마치 이어서 작업하는 것처럼 재개할 수
있습니다.

## 폴더 구조

```
<분야>/                                   # 예: 수학/, React/, 알고리즘/
  <날짜>_<분야>_<제목>_<버전>/              # 예: 2026-09-04_수학_적분법_0/
    README.md                             # 그 항목의 실제 기록
templates/
  entry-template.md                       # README.md 작성용 템플릿
CLAUDE.md                                  # Claude Code용 자동 동작 지침
```

- 같은 분야의 폴더는 `<분야>/` 아래에 모입니다.
- 같은 날 같은 제목으로 다시 만들면 버전이 자동으로 `0 → 1 → 2 …`로 올라갑니다.
- 실제 프로젝트 코드는 이 저장소에 넣지 않습니다. 코드는 각 프로젝트의 저장소에
  남기고, 여기에는 "무엇을 했고, 무엇이 남았는지" 기록만 남깁니다.

## 사용 방법

### 새 항목(폴더) 만들기

Claude에게 이렇게 요청하세요:

```
폴더로 만들줘 분야:수학 제목:적분법
```

그러면 Claude가:
1. 원격 저장소를 pull해서 최신 상태를 받고
2. `수학/` 폴더가 없으면 만들고
3. `수학/` 안에서 "적분법"이라는 제목이 이미 있는지 확인해 버전을 정하고
4. `수학/2026-09-04_수학_적분법_0/README.md`처럼 새 폴더+기록 파일을 만든 뒤
5. commit하고 push합니다.

같은 제목으로 다시 요청하면 버전만 올라간 새 폴더(`..._1`)가 만들어집니다.

### 기존 항목에 계속 기록하기

이미 만든 폴더에 이어서 작업 내용을 남기고 싶으면 "이 폴더에 오늘 작업 내용
기록해줘"처럼 요청하세요. 새 폴더를 또 만들지 않고 같은 폴더의 `README.md`를
갱신합니다.

### 새 로컬에서 작업을 이어갈 때

1. 이 저장소를 clone/pull 합니다.
   ```bash
   git clone https://github.com/Anyangta/Study_Journal.git
   # 이미 있다면
   git pull
   ```
2. 이 저장소 안(또는 이 저장소를 참조하며)에서 Claude Code를 실행하면 `CLAUDE.md`를
   자동으로 읽습니다.
3. "수학 분야 이어서 할게"처럼 말하면, 해당 분야 폴더의 최근 기록을 읽어 맥락을
   파악한 뒤 이어서 작업합니다.
